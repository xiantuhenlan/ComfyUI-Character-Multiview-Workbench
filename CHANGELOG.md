# Changelog

## 0.1.0 — 2026-11-09

- Initial independent frontend-only extension with 13 built-in views and named custom elements.
- Editable fixed canvas, drag/resize/snapping, layout-specific prompts, text/image modes and white-model PNG export.
- Layout-only favorites/history, default 24-hour history expiry and headless-body setting.
- Experimental generated-output adherence: side views, headless bodies and role transfer remain unverified/unreliable in real model tests.
